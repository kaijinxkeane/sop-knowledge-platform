# Working in Projects

A **project** is a temporary space for people from different departments working on the same thing.

## Creating a project

1. Open **Projects** and choose **New project**.
2. Give it a name, choose its members and an end date. A project lasts at most six months.
3. Optionally, ask departments to share some of their documents with the project.

Creating a project grants nothing by itself: each department's lead decides what to share, and their approval is needed before members can see it. When the project ends, its access ends too, unless it is extended.

## Inside a project

- Members can write notes in the project and read anything shared with it.
- Project notes stay in the project. They can't be moved into a department.
- The project lead can add or remove members.
