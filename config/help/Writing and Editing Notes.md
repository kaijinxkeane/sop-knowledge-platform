# Writing and Editing Notes

Use **Write** to create a new note, or open a document in the Library and choose **Edit**.

When you type the title of a new note, notes you can already read that look similar are shown. Check them first: updating one may be better than starting another.

## The editor

The toolbar works like a word processor:

- **Text style**: normal text, or heading 1, 2 or 3.
- **Bold**, **Italic**, **Strikethrough**, **Highlight** and **Code**. A button is shown as pressed when it applies to the text at your cursor.
- **Clear formatting** removes bold, italics and highlights from the selected text.
- **Bullets** and **Numbers** start a list. Press the other one to switch the whole list, or the same one again to turn the line back into normal text. Tab and Shift+Tab change the indent.
- **Callout box** adds a coloured box: Note (blue), Tip (green), Warning (amber) or Danger (red).
- **Link** links to another note. **Table** adds a table; while your cursor is in a table you can add or delete rows and columns.

Notes are saved in a standard format that also opens in Obsidian, so colours and font sizes beyond these options aren't available.

## Details

Above the text, fill in the note's details: title, type, owner, programme, stage, how often it should be reviewed and its sensitivity. The space comes from the folder the note is in.

## Saving

- Drafts save automatically a few seconds after you stop typing.
- If someone else changed the same note while you were editing, the editor merges changes to different parts for you, and asks you to choose where you both changed the same part.
- You can upload attachments such as slide decks, worksheets and images; they are linked from the note.

## Getting a change approved

When the note is ready, choose **Submit for review**. The space lead reviews it, and the assistant starts using it in answers only once that exact version is approved. See [[Reviewing and Approving Changes]].
