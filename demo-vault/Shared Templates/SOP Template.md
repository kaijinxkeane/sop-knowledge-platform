# SOP Template

Use this structure for every new SOP.

## Purpose
One sentence: what this SOP achieves and for whom.

## When to use it
The trigger (stage of a programme, request type, schedule).

## Steps
Numbered steps. One action per step. Name who does it.

## Done when
How you know it is complete.
