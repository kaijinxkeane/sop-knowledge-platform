# Laptop Setup for New Staff

1. Collect the laptop from IT on day one and sign the asset register.
2. Turn on full-disk encryption (FileVault on Mac) before signing in to any work account.
3. Install the password manager and enable two-factor authentication on every work account.
4. Install the Tailscale app and sign in with the company server address IT gives you.
5. Report a lost or stolen laptop to IT within one hour.
